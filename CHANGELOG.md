# Changelog

All notable changes to LastChance are documented here.

## [1.0.0] — 2026-11-21
### Added
- Free, unlimited money-deadline tracker: product returns, free trials, subscription renewals, warranties, bills, insurance, memberships and document/ID expiry.
- Auto deadline calculator (purchase date + 7 days to 5 years), money-at-risk totals and saved-vs-lost stats.
- Urgency dashboard (Overdue / Today / 7 days / 30 days / Later) with step-by-step checklists for every deadline type.
- One-tap calendar export (.ics) with alarms 7, 3 and 1 day before and on the day.
- Search, filters, dark mode, JSON export/import, sample data, installable PWA, Android APK build (GitHub Actions) and GitHub Pages site.
